## 🗺️ 2026 Learning & Career Roadmap

### Phase 1: Analytical Foundations & Querying
* **SQL Mastery:** Advanced JOINs, Window Functions, CTEs, Query Optimization, and Aggregations.
* **Excel / Google Sheets for Analysts:** Pivot tables, XLOOKUP, Index/Match, and financial/operational modeling.
* **Math & Statistics:** Descriptive statistics, probability distributions, hypothesis testing ($p$-values, A/B testing), regression analysis.

### Phase 2: Python for Data Analysis
* **Core Libraries:** `pandas`, `numpy`, `scipy`.
* **Data Wrangling:** Handling missing values, outlier detection, data normalization, regex text parsing.
* **Exploratory Data Analysis (EDA):** Univariate, bivariate, and multivariate analysis.

### Phase 3: Business Intelligence & Data Visualization
* **BI Platforms:** Power BI, Tableau, and Looker Studio.
* **Data Storytelling:** Building executive dashboards, tracking core KPIs (LTV, CAC, Churn, ARR).
* **Python Visualization:** `seaborn`, `matplotlib`, and interactive charts with `plotly`.

### Phase 4: Machine Learning & Predictive Modeling
* **Supervised Learning:** Linear/Logistic Regression, Decision Trees, Random Forests, XGBoost.
* **Unsupervised Learning:** K-Means Clustering, PCA, Anomaly Detection.
* **Model Evaluation:** ROC-AUC, Precision/Recall, RMSE, Cross-Validation.
